# 立場ごとの公開範囲(校外・部外・部内)

サイトを見る人を3つの立場に分け、立場ごとに見られる範囲を決めています。

| 立場 | だれか | 見られるもの |
|---|---|---|
| 校外 | ログインしていない人 | 公開ページと、公開範囲が「校外まで」のお知らせ |
| 部外 | ログインしているが放送部員ではない人 | 上に加えて、「部外まで」のお知らせとマイページ |
| 部内 | 放送部員 | 上に加えて、「部内のみ」のお知らせ、機材・予定・マニュアル・動画 |

部内のうち、スタッフ権限(`is_staff`)も持つ人を「編集担当」と呼びます。名簿・場所・お知らせ・マニュアル・予定の編集は編集担当だけができます。スタッフ権限だけあっても、部員でなければ何も編集できません。

## 「部内」になる条件

名簿(`/roll/` または管理画面)で、次の2つがそろっているアカウントです。

- 名簿の行に、その人の**アカウントが連携**されている
- その行の**「放送部員」にチェック**が付いている

スーパーユーザーは、名簿に関係なく部内(編集担当)として扱います。

## 反映するときの手順

**この変更を入れると、名簿と連携していないアカウントは「部外」になり、機材や予定が見られなくなります。** 先に名簿を整えてください。

1. 反映前に、スーパーユーザーでログインできることを確かめる。
2. `python manage.py migrate` を実行する。
3. 名簿で、部員のアカウント連携と「放送部員」のチェックを確認する。CSV取り込みなら「アカウント」列と「部員」列で一括設定できます。
4. 部員のアカウントで、機材や予定が開けることを確かめる。

顧問の先生など、生徒でない人にも見せたい場合は、その人の名簿の行で「放送部員」にチェックを付けます。

## お知らせの公開範囲

お知らせごとに「校外まで」「部外まで」「部内のみ」から選びます。

- 以前の「限定公開」のお知らせは、移行時にいちばん狭い**「部内のみ」**にしています。部外の人にも見せたいものは「部外まで」に変えてください。
- 新着投稿のPush通知は、「校外まで」のお知らせだけに送ります。

## アカウントの作り方

- ユーザー名とパスワードでの自己登録(`/accounts/signup/`)は閉じています。
- アカウントは、学校のGoogleアカウント(`@rakunan-h.ed.jp`)でのログインか、管理画面からの作成でのみ増えます。

## パスワードの回数制限

- ログインと昇格パスワードは、**同じアカウントに対する失敗が1時間に5回**たまると、それ以上試せなくなります。1時間たつと自動で解除されます。
- 記録はDBにあるので、ログインし直しても解除されません。
- すぐ解除したいときは、管理画面ではなくシェルで消します。

  ```python
  from accounts.models import FailedAttempt
  FailedAttempt.objects.filter(key="ユーザー名").delete()
  ```

- 他人のユーザー名でわざと5回間違えると、その人のパスワードログインを1時間止められます。Googleログインは影響を受けません。
- 管理画面(`/admin/`)には専用のログイン画面がなく、サイトのログイン画面を通ります。

## Python の共通関数

立場の判定は `accounts.audience` にまとめています。`is_staff` を直接見ずに、こちらを使ってください。

```python
from accounts.audience import (
    is_outside_school,     # 校外か
    is_school_non_member,  # 部外か
    is_club_member,        # 部内か
    is_club_editor,        # 部内の編集担当か
    visible_audiences,     # その人が見てよい公開範囲の一覧
)
from accounts.decorators import (
    school_required,       # 部外・部内(ログインしていれば誰でも)
    club_member_required,  # 部内のみ
    club_editor_required,  # 編集担当のみ
)
```

テンプレートでは `{% if is_club_member %}` と `{% if is_club_editor %}` が使えます。

立場の決め方を変えたいとき(例: 編集担当を役職者だけにする)は、`accounts/audience.py` だけを直します。
